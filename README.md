# Hevy Growth Audit

**Live → https://eddieatadapty.github.io/hevy-flow-rebuild-v2/**

Five ideas to turn more Hevy users into subscribers, each built into a clickable version of Hevy's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Name their goal on the paywall | +10–20% CR to purchase |
| 02 | Ask for the account after the plan | +5–10% CR to purchase |
| 03 | Hold both permission prompts until after the paywall | +10–15% CR to purchase |
| 04 | Put your 4.9 stars by the plans | +5–10% CR to purchase |
| 05 | Offer a second plan on Not now | +10–15% ARPU |

Every price, rating and feature comes from Hevy's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Hevy. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
